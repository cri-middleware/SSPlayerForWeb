# @spritestudio/ssplayer-rmmz

**SpriteStudio 7**（`.ssab`）アニメーションを **RPG ツクール MZ** で再生するプラグインです。
キャラやピクチャと正しい前後関係（Zオーダー）で表示されます。

> **対象読者:** RPG ツクール MZ でゲームを作る人。プラグインコマンドで SpriteStudio アニメを追加します（コード不要）。プラグイン自体をいじる場合は → [コントリビューター向け](#コントリビューター向け--ソースからビルド)。
> **ステータス:** 実験的 / alpha（`7.0.0-alpha.1`）・private（**npm 未公開**）。
> 初回リリース後、**GitHub Releases** にプラグイン ZIP を添付して配布します。まだリリースは
> 存在しないため、現時点ではソースからビルドします
> （→ [コントリビューター向け](#コントリビューター向け--ソースからビルド) 参照）。

▶️ **[オンラインデモ](https://cri-middleware.github.io/SSPlayerForWeb/examples/rmmz/)** —
同梱のサンプル MZ プロジェクトをブラウザで動かせます（🚧 初回リリース後に公開）。

# プラグインの使い方

*RPG ツクール MZ でゲームを作る方向けに、導入からアニメの変換、イベントコマンドでの操作までを説明します。*

## 1. 導入

1. `ssplayer-rpgmakermz.js` と `ssruntime_bg.wasm` を用意します。**まだリリースは公開されて
   いません** — 現時点では自分でビルドしてください
   （→ [コントリビューター向け](#コントリビューター向け--ソースからビルド) 参照）。初回リリース
   後は、**GitHub Releases** からプラグイン ZIP をダウンロードできるようになります。
2. **両方**を `js/plugins/` にフラットに配置します（WASM は `.js` と同じ場所に置いてください）。
3. プラグイン管理で **ssplayer-rpgmakermz** を有効化します。パラメータはありません（WASM は
   プラグイン `.js` と同じフォルダから自動で読み込まれます）。

## 2. アニメを変換する（.sspj → .ssab）

`.sspj` は SpriteStudio で編集するプロジェクトファイル、`.ssab` はプラグインが実際に再生する
変換済み（プリビルド）のランタイムファイルです。`.sspj` を次のいずれかで変換してください。

- **Web（インストール不要）：** ホスト版コンバータ
  **<https://cri-middleware.github.io/SSPlayerForWeb/ssconverter/>**（🚧 初回リリース後に利用可能）を開き、`.sspj`
  プロジェクトが入ったフォルダ（ディレクトリ）をドロップすると `.ssab`（＋テクスチャ）が
  zip ファイルでダウンロードできます。
- **デスクトップ：** [**SSConverterGUI**](https://github.com/cri-middleware/SSConverterGUI/releases) を使います。

変換して出てきた `.ssab` **とテクスチャ** は、ゲームプロジェクト直下の
`spritestudio/<プロジェクト名>/` フォルダに置きます。`img/` の **中ではなく**、`img/` と
並ぶ位置です。デプロイ時に未使用ファイルが削除されるのは `img/` の中だけなので
（[デプロイメント](#4-デプロイメント) 参照）、そこから出しておくことが SS 素材を守る鍵です。

```
MyGame/
├── img/                     ← 「未使用ファイルを含まない」で削除される
├── js/plugins/
│   ├── ssplayer-rpgmakermz.js
│   └── ssruntime_bg.wasm
└── spritestudio/            ← 安全
    └── Ringo/
        ├── Ringo.ssab
        └── Ringo.png        ← テクスチャは .ssab と同じ場所
```

こうしておくと `.ssab` のパスが `spritestudio/<プロジェクト名>/<プロジェクト名>.ssab`
（例: `spritestudio/Ringo/Ringo.ssab`）という決まった形になり、`SS表示` コマンドの
`SSABファイル` にそのまま入力できます。テクスチャは `.ssab` からの相対で解決されるため、
同じフォルダに置いたままにしてください。

## 3. プラグインコマンド

イベントの「プラグインコマンド」から `ssplayer-rpgmakermz` を選んで使います。SS アニメは
MZ の**ピクチャ**に乗るので、**ピクチャの移動**・拡大・Zオーダー・セーブ/ロードがそのまま効きます。

### 表示・割り当て

| コマンド | 内部名 | 説明 |
|---|---|---|
| SS表示 | `showSS` | ピクチャを作成し、アニメを割り当てて再生開始まで一括で行います。引数: `ピクチャ番号` / `SSABファイル`（例 `spritestudio/Ringo/Ringo.ssab`） / `アニメーション名`（空欄で先頭） / `X` / `Y` / `拡大率` / `ループ回数` / `シグナル→スイッチ` / `完了までウェイト`。 |
| SSをピクチャに割当 | `setSSAsPicture` | 標準の「ピクチャの表示」で既に出したピクチャに、SS を後付けします。位置や消去は標準の「ピクチャの移動/消去」で操作してください（1つのピクチャ番号を、素のピクチャ表示と SS で同時に使わないでください）。 |

### アニメーション制御

| コマンド | 内部名 | 説明 |
|---|---|---|
| SSアニメ切替 | `changeSSAnimation` | 同じ `.ssab` 内の別のアニメーションへ切り替えます（再ロードなし）。 |
| SSワンショット再生 | `playSSOnce` | アニメを再生し、終わったら**現在のループへ自動で戻ります**（待機 → 表情 → 待機）。`ループ回数` で再生回数を指定できます。 |
| SS連続再生 | `playSSSequence` | カンマ区切りのアニメ列を再生します。末尾以外は1回ずつ、末尾だけループします（例 `attack1,attack2,wait1`）。 |
| SS再生速度 | `setSSSpeed` | 再生速度の倍率を指定します。サブフレーム補間により低速でも滑らかに再生されます。 |

### パーツ上書き（色・セル・表示）

アニメのキーフレームより**優先**して、特定パーツの見た目を実行時に差し替えます。設定はピクチャに
保存されるため、**セーブ／ロードをまたいでも復元されます**（再生位置は先頭から再開します）。

| コマンド | 内部名 | 説明 |
|---|---|---|
| SSパーツ色変更 | `setSSPartColor` | 1 パーツを着色します。色は `#RRGGBB` / `#RRGGBBAA` で指定（MZ に色指定の引数型が無いため 16 進文字列です）。合成方法はパーツカラーと同じ 4 種。**通常パーツのみ**。 |
| SSパーツ表示切替 | `setSSPartVisibility` | 1 パーツを強制的に非表示にします（解除も可）。`子パーツにも波及` を ON にすると子孫ごと隠せます — アニメの非表示は波及しないため、部位ごと隠すにはこちらを使います。 |
| SSパーツセル差替 | `setSSPartCell` | 1 パーツが描くセルを差し替えます（装備の差し替えなど）。セルマップ名に `.ssce` は付けません。**通常パーツとマスクパーツのみ**。 |
| SSパーツ上書き解除 | `clearSSPartOverrides` | 上書きを解除します。`パーツ名` を空欄にするとそのピクチャの全パーツが対象です。 |

> **優先度**（色・セルのみ）: `次のキーフレームに譲る` / `アニメが変わるまで保持`（既定）/
> `恒久`。アニメを切り替えると、**`恒久` 以外の上書きは解除されます**（ランタイムの仕様に合わせて
> セーブ内容も同時に整理されます）。表示の上書きに優先度はなく、アニメ切替で必ず解除されます。

### 再生・ライフサイクル

| コマンド | 内部名 | 説明 |
|---|---|---|
| SS再生 / 一時停止 / 停止 / 削除 | — | `ピクチャ番号` で操作します。 |
| SS完了待ち | — | 指定したループ回数をすべて再生し終えるまでイベントを待機させます（有限ループで使ってください。`0` は無限ループの別名なので待ち続けます）。 |

### リップシンク（喋る立ち絵・応用）

| コマンド | 内部名 | 説明 |
|---|---|---|
| SSリップシンク設定 | `setSSTalk` | ピクチャを**話者名**（メッセージの名前欄）に紐づけます。その話者のメッセージ表示中は `発話` アニメを、それ以外は `待機` アニメを再生するので、喋っているキャラだけが口パクします。 |
| SSリップシンク解除 | `clearSSTalk` | 紐づけを解除します。会話が終わったら呼んでください。 |

> `アニメーション名` を空欄にすると先頭のアニメを自動で採用します。存在しない名前を指定すると、
> コンソールに警告と**利用可能なアニメ名の一覧**を表示します（MZ エディタは `.ssab` を読めない
> ため、動的なプルダウンは仕様上できません）。

## 4. デプロイメント

**SS 素材を `img/` の外に置けば、「未使用ファイルを含まない」は ON のままで構いません。**
公式ヘルプの通り、このオプションが削除対象にするのは `img/`・`audio/`・`effects/` の中だけ
です。`.ssab` とテクスチャは本プラグインが動的に読み込むためツクールからは未使用に見え、
`img/` の中にあると削除されますが、プロジェクト直下の `spritestudio/` は `js/plugins/` と
同じくそもそも対象外です。登録作業も追加設定も要りません。

> **移行：** 素材がまだ `img/spritestudio/` にある場合は、フォルダごと 1 階層上の
> `spritestudio/` へ移動し、各「SS表示」「SSをピクチャに割当」コマンドの `SSABファイル`
> から先頭の `img/` を外してください。

**トレードオフ — 暗号化。** *画像ファイルの暗号化* も対象は `img/`・`audio/` だけのため、
`img/` の外に置いたテクスチャは暗号化されません。テクスチャを暗号化したい場合は、`.ssab` と
テクスチャを分けるのではなく **`spritestudio/` フォルダごと `img/` の下へ戻して**ください。
`.ssab` は画像ではないので暗号化されませんが、同じフォルダにあるテクスチャは暗号化され、
`ImageManager` 経由で読み込むため復号は自動です。ただしその場合は **「未使用ファイルを
含まない」を OFF にする**か、デプロイ後に **`img/spritestudio/` を出力先へコピー**する必要が
あります。

## 既知の制限

- **ピクチャの不透明度／色調は SS アニメに反映されません**（常に不透明で描画されます）。
  移動・拡大は反映されます。
- **一部の画面効果は通常のピクチャと挙動が異なります**（一部の PIXI フィルタを直接掛けると
  位置がズレることがあり、ループ音は1回だけ再生されます）。MZ 自身のフラッシュ／色調の
  オーバーレイには影響しません。

技術的な理由と対応予定は [コントリビューター向け → しくみ](#しくみ) に記載しています。

# コントリビューター向け — ソースからビルド

*利用者はここまで。以下はこのパッケージを開発する人向けです。*

*プラグインや SDK に手を入れる方向けに、アーキテクチャ、ソースからのビルド、同梱ハーネスを説明します。*

## しくみ

`.ssab` を **MZ 自身の PixiJS v5 レンダラへ直接描画**しています（MZ の Tilemap や同梱の
Effekseer と同じ方式です）。別 canvas のオーバーレイにならないため、キャラやピクチャと正しい
前後関係で表示されます。

- **ランタイム**：**非 SIMD（スカラー）版**の SpriteStudio WASM を同梱しているため、MZ 同梱の
  NW.js（WebAssembly SIMD 非対応の Chromium）でも起動フラグなしに動作します。初期化に失敗した
  場合は SS アニメだけが無効化され、ゲーム自体は起動します（理由はコンソールに表示されます）。
- **Layer 3（レンダラ）**：`SSPlayer` は `PIXI.Container`、`SSPlayerRenderer` は登録済みの
  `PIXI.ObjectRenderer`（`'ssplayer'`）で、[`@spritestudio/ssplayer-webgl`](../ssplayer-webgl)
  の `SSWebGLRenderer` を MZ の共有 `gl` 上で駆動します。これを再利用することで、**マスク・
  エフェクト・SS特殊シェーダ13種・インスタンスパーツがそのまま動作**します。生 GL 描画の前後は、
  MZ の Effekseer スプライトと同一の WebGL ステート退避／復元で挟んでいます。
- **Layer 4（プラグイン）**：ドロップイン型の IIFE です。`Scene_Boot.isReady` で WASM の初期化を
  待ち、Game_Picture ↔ Sprite_Picture ブリッジでアニメをピクチャにアタッチします（MZ の移動・
  拡大が適用され、セーブ／ロードで状態が復元されます）。テクスチャは `ImageManager`、音声は
  `AudioManager` に委譲します。
- **独自タイマーを持ちません**：再生は親スプライトの `update()` からのみ進むため、メニューや
  メッセージ待ちのときにゲームと一緒にピタッと止まります。

**既知の制限（技術的な内訳）。** 平易な要約は上の [既知の制限](#既知の制限) を参照してください。
内部的には次のとおりです。

- MZ の**不透明度／色調**は SS の描画へ渡していません（常に不透明で描画）。移動・拡大は反映されます。
- SS スプライトに **PIXI フィルタを直接掛ける**と位置がズレることがあります（投影が**フル
  スクリーン固定**のため）。MZ の画面効果（フラッシュ・色調）は別オーバーレイなので影響ありません。
- ループ SE（`loopNum`）は1回だけ再生されます。**ステンシルマスク**には MZ canvas のステンシル
  バッファが必要です（既定で有効です）。

上記の不透明度／色調・投影の制限は、いずれも `SSWebGLRenderer` への小さな改修（投影行列と
α/tint uniform の注入）できれいに解決できます（今後対応予定です）。

## ビルドして試す

```sh
pnpm --filter @spritestudio/ssplayer-rmmz build      # dist/browser/ssplayer-rpgmakermz.js
pnpm --filter @spritestudio/ssplayer-rmmz pack       # dist/pack/ssplayer-rmmz-plugin-<v>.zip
```

同梱の MZ サンプルで動かすには、次のようにします。

```sh
pnpm --filter rmmz-example run sync:plugin   # ビルド済みプラグイン + 非SIMD wasm を js/plugins/ へ
pnpm deploy-examples                         # SS-SDK テストプロジェクトを spritestudio/ へ変換
nw examples/rmmz-example/SampleProject       # テストプレイ（または MZ エディタで開く）
```

`sync:plugin` はビルド済みプラグインを同期します（`tyranoscript-example` と同じ方式です）。
`deploy-examples` はテストアセットの変換・配布を一手に担う単一の入口です。NW.js がなければ、
`examples/rmmz-harness` のブラウザハーネス（実 `SSPlayer` / `SSPlayerRenderer` を PixiJS v5 上で
駆動します）を使ってください。
