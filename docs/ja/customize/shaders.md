# シェーダーとブレンドモード

どちらのレンダラーも同じ機能を同じ結果で実装しています。`ssplayer-webgl` は素の GLSL、
`ssplayer-pixi` は Pixi のシェーダー（GLSL と WGSL の両方）なので、WebGPU バックエンドでも動作します。

## ブレンドモード

ブレンドモードはポストプロセスではなく、**固定機能の GPU ブレンド**です。背景を読み取るモード（**Screen / Exclusion / Invert**、および加算）は、その時点でフレームバッファにあるものを対象に合成します。シェーダー出力は乗算済みアルファで、アルファは常に premultiplied coverage としてブレンドされます。

| SpriteStudio のモード | 描画方法 |
|---|---|
| ミックス、加算、減算、乗算 | 固定機能の完全な等価物 |
| スクリーン、除外、反転 | 完全一致。これらは背景を読み取ります |
| 乗算済みアルファ、乗算2 | **乗算**で近似 |
| スクリーン2 | **スクリーン**で近似 |
| 除算2、オーバーレイ2 | **ミックス**で近似 |

下 3 行には GPU ネイティブの等価物がないため、エディタとの差が出るとすればこれらのモードです。それ以外は一致するはずです。

### 背景が正しくないと合わない

背景を読み取るモードは、読み取るべき実体の背景があって初めて正しく描画されます。「ブレンドがエディタと全然違う」の原因はたいていここです。

**PixiJS** — 背景は `Application` の `backgroundColor` です。オーサリング環境に合わせてください。

**WebGL** — 加算や背景読み取り系のモードを使うアニメーションでは `backgroundColor` を渡します。

```ts
const surface = new SSSurface(canvas, { backgroundColor: 0x000000 });
const player = surface.createPlayer();
```

```html
<ss-player src="/assets/Effect.ssab" animation="fire" background="#000000"></ss-player>
```

::: warning 透明な canvas と加算合成
`backgroundColor` を省略すると、オーバーレイとして重ねられるように canvas は**完全な透明**でクリアされます。この状態では加算スプライトに加算する相手が存在しないため、不透明な黒の上で焼き込まれたグローのテクスチャは、その黒がそのまま不透明なブロックとして描画されます。これは乗算済みアルファ合成の性質によるもので、`ssplayer-pixi` も同じく不透明な `backgroundColor` の上に描くことで回避しています。
:::

## SS 統合シェーダー

SpriteStudio の統合シェーダー（`SHDR` アトリビュート、`ss-*`）は両レンダラーに移植されています。セル矩形は UV コーナーから算出されるため、セル周辺をサンプリングする効果もセル内に収まります。

対応しているビルトインは次の 13 種です: `ss-sepia`、`ss-hsb`、`ss-step`、`ss-pix`、`ss-noise`、
`ss-bmask`、`ss-outline`、`ss-blur`、`ss-wave`、`ss-move`、`ss-scatter`、`ss-circle`、`ss-spot`。これ以外のシェーダー ID は、通常描画にフォールバックします。

プログラムは初回使用時にコンパイルされてシェーダー ID ごとにキャッシュされ、シェーダーパーツを含まないフレームはこの経路自体をスキップします。したがってシェーダーを使わないアニメーションがこの機能の存在によってコストを払うことはありません。

::: warning マスク対象のパーツではシェーダーが無効になります
マスクの対象であり、かつ `ss-*` シェーダーを持つパーツは、マスク処理の経路を通常のプログラムで通るため、シェーダーが適用されません。これは両レンダラーの現在の挙動です。両方が必要な場合は、オーサリング時にパーツを 2 つに分けてください。
:::

シェーダーパーツはバッチも分割します。[パフォーマンスチューニング](/ja/customize/performance#バッチが分割される要因)を参照してください。

::: tip 見え方の検証
仕様値よりも **SpriteStudio エディタでの見え方に合わせる**ことを優先し、
`examples/pixi-example` でサンプル（`BlendMode.ssab` / `Shader.ssab` /
`PartsColor.ssab` など）を並べて確認するのが確実です。
:::
