# 制約と適用範囲

現行の SpriteStudio Player for Web で配信する際に把握しておくべき制約をまとめています。
対応している機能については [基本的な再生](/ja/usage/basic) と各使い方ガイドを参照してください。

::: info このドキュメントは随時更新されます
確認できた項目から追記しており、各パッケージの進化に応じて記述や範囲が変わる場合があります。
:::

本リポジトリは monorepo のため、制約は 3 つの階層のいずれかに属します。各セクションでどの階層の
話かを明示しています。

## 未実装の機能 — すべてのレンダラー共通

`ssplayer-webgl`・`ssplayer-pixi`、およびそれらの上に構築されたすべてのフレームワーク連携に
適用されます。

::: warning
- **テキストパーツ** — 描画されません。ランタイムは描画プラン上の位置を確保しますが、グリフは
  提供しません（グリフのレイアウトとラスタライズは Player 側の責務です）。本リポジトリのどの
  レンダラーにもテキスト描画パスがまだありません。
- **9 スライスパーツ** — 描画されません。ランタイムはグリッド全体を専用の `Nines` バッファに
  構築しますが、どのレンダラーもまだそれを読んでいないため、セルが引き伸ばされた状態ではなく
  何も表示されません。
:::

どちらのパーツ種別も描画順序上の位置は保持されるため、これらを使ったアニメーションはエラーに
ならず、該当パーツが欠けた状態で再生されます。出荷するアニメーションでは、作画時に通常パーツへ
置き換えてください。

**シーケンス（`.ssqb`）** は関連しますが別の事情です。変換では `.ssqb` が生成され、Player も
`.ssab` と一緒に扱いますが、シーケンスの*再生*は共通ランタイム側が未実装のため、すべての公式
Player で利用できません。[共通の制限事項](https://cri-middleware.github.io/SpriteStudio-Docs/ja/sdk/limitations/)
を参照してください。

## ブラウザ要件

::: warning WebAssembly SIMD が必須
ランタイムは WebAssembly SIMD 命令を使用してビルドされており、**SIMD 非対応のブラウザでは
動作しません**。フレームワーク連携を含む本リポジトリのすべてのパッケージが対象です。配信先の
ブラウザ要件として扱ってください。
:::

ブラウザ版コンバーター `ssconverter-web` はさらに、フォルダー選択に **File System Access API**
（`showDirectoryPicker` / ディレクトリのドラッグ＆ドロップ）を使用するため、**Chromium 系
ブラウザ**（Chrome / Edge など）が必要です。Firefox・Safari では動作しません。
[アセットの準備](/ja/usage/assets) を参照してください。

## 各パッケージの入手方法

レンダラーは npm パッケージですが、フレームワーク連携はホスト側のプラグイン機構が読み込む
IIFE バンドルとして提供されるため、**npm からはインストールできません**。

| パッケージ | 入手方法 | ステータス |
|---|---|---|
| `@spritestudio/ssplayer-core` | npm | beta |
| `@spritestudio/ssplayer-webgl` | npm | beta |
| `@spritestudio/ssplayer-pixi` | npm | beta |
| `@spritestudio/ssconverter-core` | npm | beta |
| `@spritestudio/ssplayer-rmmz` | プラグイン ZIP、または[ソースからビルド](/ja/usage/rmmz#ソースからビルドする) | **実験的（alpha）** |
| `@spritestudio/ssplayer-tyranoscript` | プラグイン ZIP、または[ソースからビルド](/ja/usage/tyrano#ソースからビルドする) | beta |
| `@spritestudio/ssplayer-tyranobuilder` | `ssplayer.tbp` をティラノビルダーのプラグイン設定から追加 | beta |
| `ssconverter-web` | 未公開 — ローカルビルドで実行 | — |

## RPG ツクール MZ（実験的）

`@spritestudio/ssplayer-rmmz` は **alpha** です。タグ体系と挙動は変更される可能性があります。
[RPG ツクール MZ で使う](/ja/usage/rmmz) を参照してください。

::: warning
- **ピクチャの不透明度・色調は SS アニメーションに影響しません** — 常に不透明で描画されます。
  *移動*と*拡大縮小*は反映されます。
- **一部の画面エフェクトは通常のピクチャと挙動が異なります。** 一部の PIXI フィルターは
  アニメーションの位置をずらすことがあり、ループ再生の効果音は 1 回しか鳴りません。ツクール
  本体のフラッシュ・色調変更は影響を受けません。
- **デプロイ時の「未使用ファイルを含まない」でアニメーションが削除されます。**
  `img/spritestudio/` 配下の `.ssab` とテクスチャは動的に読み込まれるため、ツクールからは未使用と
  判定されます。このオプションをオフにするか、出力後に `img/spritestudio/` をコピーしてください。
:::

不透明度・色調と投影の制約は、いずれも `SSWebGLRenderer` への小さな拡張（投影行列の注入と
アルファ／色調ユニフォームの追加）で解消できる見込みで、今後の対応予定です。

## TyranoScript / ティラノビルダー

どちらも **beta** です。オーサリング用のタグ体系は揃っていますが、`7.0.0` までに名称や挙動が
変更される可能性があります。[TyranoScript / TyranoBuilder で使う](/ja/usage/tyrano) を参照して
ください。

::: warning TyranoScript
`[cm]` / `[clearfix]` の自動フック、frame 精密復元、Tyrano 音量スライダー連動は今後の対応予定です。
進捗は [ROADMAP.md](https://github.com/cri-middleware/SSPlayerForWeb/blob/main/ROADMAP.md) を
参照してください。
:::

::: warning ティラノビルダー
- **コンポーネントが未提供の機能があります** — パーツ単位の色・表示切り替えと、アニメーションと
  話者の紐付けです。これらはティラノビルダーの TyranoScript コード用コンポーネントから
  [`[ss_*]` タグ](/ja/usage/tyrano) で記述してください。
- **無料版が読み込めるプラグインは 2 つまで**で、本プラグインはその 1 つを消費します。
- **`ssplayer.tbp` はリネームしないでください。** ティラノビルダーはファイル名からプラグイン名を
  取得します。
:::

## 再生機能の制約

以下は共通コア `libssruntime` に由来するため、本リポジトリのすべてのパッケージに適用されます。
すべての公式 Player にも共通するため、詳しい説明と、その他の共通制約（embedded モード、`.ssab` の
入力検証を行わない件など）はポータルにまとめてあります:
**[共通の制限事項](https://cri-middleware.github.io/SpriteStudio-Docs/ja/sdk/limitations/)**

::: warning
- **`independent = true` のパーツ（インスタンス／エフェクト）は逆再生・シークで正しく動作しません。**
  正しいのは順方向の再生（順方向のフレームスキップを含む）のみです。
- **シークは通過したフレームのイベントを発火しません。** 発火するのは移動先フレームの
  `UserData` / `Signal` / `Audio` のみです。
- **オーディオは逆再生できません。** 実質的な進行方向が逆向き（逆再生、ピンポンの復路、負の
  再生速度）の場合、サウンドはスキップされます。
- **アニメーションブレンドは同一 `.ssab` 内のみ**で、ブレンドする全アニメーションが同一パーツに
  同一セルを割り当てている必要があります。
- **ランタイムは音声を再生しません。** `onAudio` はサウンドの参照とタイミングを通知するのみで、
  実際の再生はアプリ側の責務です（フレームワーク連携では各プラグインが実装済みです）。
:::
