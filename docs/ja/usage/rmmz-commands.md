# RPG ツクール MZ のプラグインコマンド

RPG ツクール MZ のプラグインが追加するプラグインコマンドです。プラグインの導入、アニメーションの変換、ゲームのデプロイは [RPG ツクール MZ で使う](/ja/usage/rmmz) にあります。

イベントの **プラグインコマンド** → `ssplayer-rpgmakermz` から実行します。SS アニメーションは
MZ の **ピクチャ** に載るため、*ピクチャの移動* / 拡大縮小 / Z 順 / セーブ・ロードがそのまま適用されます。

以下のコマンド名は MZ エディター（日本語）に表示される名称です（括弧内は内部のコマンド ID）。

## 表示 / 付与 {#show-attach}

- **SS表示**（`showSS`）— ピクチャの作成とアニメーションの付与を一括で行います。引数は `ピクチャ番号`・`SSABファイル`（例: `spritestudio/Ringo/Ringo.ssab`）・`アニメーション名`・`X座標`・`Y座標`・`拡大率(%)`・`ループ回数`・`シグナル→スイッチ`・`完了までウェイト` です。`ループ回数` は、`-1`（または `0`）で無限、`1` で 1 回、それ以外は再生する回数です（既定 `-1`）。`シグナル→スイッチ` は、アニメが SpriteStudio でフレームに置かれた目印（シグナル）を出したときに ON になるスイッチで、自動では OFF に戻りません。`0` は指定なしです。`完了までウェイト` を使うときは `ループ回数` を 1 以上にしてください。無限ループのアニメは終わらないためです。
- **SSをピクチャに割当**（`setSSAsPicture`）— *ピクチャの表示* で既に表示済みのピクチャへ SS を後付けします。以降は標準の *ピクチャの移動 / 消去* で操作します。同じピクチャ番号を *ピクチャの表示* と SS の両方で操作しないでください。

## アニメーション制御 {#animation-control}

- **SSアニメ切替**（`changeSSAnimation`）— **同一 `.ssab` 内**の別アニメーションへ再ロードなしで切り替えます。
- **SSワンショット再生**（`playSSOnce`）— 指定回数だけ再生し、**現在のループへ自動的に戻ります**（待機 → 表情 → 待機 など）。
- **SS連続再生**（`playSSSequence`）— カンマ区切りのリストを再生し、末尾以外は各 1 回、**末尾のみループ**します（例: `attack1,attack2,wait1`）。末尾に入ると、それがピクチャのアニメになります。
- **SS再生速度**（`setSSSpeed`）— 再生速度の倍率です（サブフレーム補間により低速でも滑らかです）。

**SSアニメ切替**・**SSワンショット再生**・**SS連続再生**・**SSリップシンク設定** は `クロスフェード時間（ミリ秒）` を取ります。0 より大きいと、表示中のアニメからその時間をかけてクロスフェードし、0（既定）ならすぐに切り替えます。

## トラック（アニメの重ね合わせ） {#tracks-layering-animations}

ピクチャ自身のアニメ（トラック 0）の上に、1 番以上のトラックで別のアニメを重ねられます（歩きに身振りを、ポーズに表情を重ねる、など）。トラックはピクチャと一緒にセーブされます。ピクチャのアニメをクロスフェード**せずに**切り替えると、プレイヤー本体と同じくトラックは空になります。クロスフェードなら残ります。

- **SSトラック設定**（`setSSTrack`）— トラックにアニメを置きます。`強さ（α）`、`合成方法`（ミックス、またはセットアップポーズからの差分を足す加算）、`ループ回数`、`クロスフェード時間（ミリ秒）` を指定できます。
- **SSトラックフェード**（`fadeSSTrack`）— トラックの強さを、`時間（ミリ秒）` をかけて `目標の強さ（α）` まで変えます。`完了までウェイト` でフェードが終わるまでイベントを止めます。
- **SSトラック解除**（`clearSSTrack`）— トラックを空にします。徐々に消したい場合は、先に強さ 0 へフェードしてください。

## パーツ上書き（色 / セル / 表示） {#part-overrides-colour-cell-visibility}

アニメのキーフレームより **優先** して、特定パーツの見た目を実行時に差し替えます。設定はピクチャに保存されるため、**セーブ / ロードをまたいでも復元されます**。

- **SSパーツ色変更**（`setSSPartColor`）— 1 パーツを着色します。色は `#RRGGBB` / `#RRGGBBAA`
  で指定します（MZ に色の引数型が無いため 16 進文字列です）。4 つの合成方法は、SpriteStudio のパーツカラーと同じものです。**通常パーツのみ**。
- **SSパーツ表示切替**（`setSSPartVisibility`）— 1 パーツを強制的に非表示にします。`子パーツにも波及` を ON にすると子孫ごと隠せます — アニメの非表示は波及しないため、部位ごと隠すにはこちらを使います。
- **SSパーツセル差替**（`setSSPartCell`）— 1 パーツが描くセルを差し替えます（装備の差し替えなど）。セルマップ名に `.ssce` は付けません。**通常パーツとマスクパーツのみ**。
- **SSパーツ上書き解除**（`clearSSPartOverrides`）— `パーツ名` を空にするとそのピクチャの全パーツが対象です。

**優先度**（色 / セルのみ）は `次のキーフレームに譲る` / `アニメが変わるまで保持`（既定）/ `恒久（アニメ変更をまたいで維持）`の 3 段階です。アニメを切り替えると **`恒久` 以外は解除されます**（セーブ内容も同時に整理されるため、ロード時に復活することはありません）。表示の上書きに優先度はなく、アニメ切替で必ず解除されます。ただしクロスフェード（`クロスフェード時間（ミリ秒）` が 0 より大きい切り替え）では、どの上書きも解除されません。

## パーツトラッキング（スクリプト専用） {#part-tracking-script-only}

自前の表示オブジェクトをパーツに追従させる機能に、**プラグインコマンドはありません**。スクリプトから `SSPlayer` を取得して `attachToPart()` を呼んでください。詳しくは[パーツトラッキング](/ja/customize/part-following) を参照してください。

## 再生 / ライフサイクル {#playback-lifecycle}

- **SS再生 / SS一時停止 / SS停止 / SS削除**（`playSS` / `pauseSS` / `stopSS` / `removeSS`）と
  **SS完了待ち**（`waitForSS`）を `ピクチャ番号` で操作します。**SS完了待ち** は、そのピクチャの `ループ回数` をすべて再生し終えるまでイベントを止めます（`ループ回数` は有限にしてください。`0` は無限ループの別名なので、止まり続けます）。

## リップシンク（会話ポートレート・上級） {#lip-sync-talking-portrait-advanced}

- **SSリップシンク設定**（`setSSTalk`）— ピクチャを `話者名`（名前ボックス）に紐付け、その話者のメッセージ表示中は `発話アニメ`、それ以外は `待機アニメ` を再生します。
- **SSリップシンク解除**（`clearSSTalk`）— 紐付けを解除します（会話終了時に実行します）。

`アニメーション名` を空にすると、**SS表示** と **SSをピクチャに割当** では先頭のアニメーションを再生し、**SSアニメ切替** では今のアニメーションのままになります。**SSワンショット再生**・**SS連続再生**・**SSトラック設定** では名前が必要です。`.ssab` に無い名前を指定するとコンソールに警告が出て、実際の名前の一覧が表示されます（MZ エディターは `.ssab` を読めないためドロップダウンを作れません）。
