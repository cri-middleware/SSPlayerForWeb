# パフォーマンスチューニング

## 再生オプション

```ts
player.subframe = false;        // サブフレーム補間を無効化（既定は on）。負荷を抑えたいとき
player.frameSkipEnabled = true; // 負荷が高いときフレームをスキップして追従
player.speedScale = 1.0;        // 再生速度倍率
```

- **`subframe`**: **既定でオン**。高リフレッシュレートやスロー演出で滑らかになります。
  多数同時再生で計算コストが重い場合は `false` に。
- **`frameSkipEnabled`**: 描画が間に合わないときに再生タイミングを優先します。

## 設計上の高速化

- **Direct Drawing（バッチ描画）**: `ssplayer-pixi` は描画をバッチ化し、多数の
  キャラクターを少ないドローコールで描きます。
- **Zero-Copy**: トランスフォームやジオメトリは WASM メモリを直接参照する
  `Float32Array` ビューで受け渡し、毎フレームのコピーを避けます。
- **リソース共有**: 同じ `.ssab` を複数のプレイヤーで使う場合、パース済みリソースが
  キャッシュされ、アセットの WASM メモリフットプリントを共有します。

## 計測のヒント

まず `examples/pixi-example` で対象アセットを多数配置し、ブラウザの
パフォーマンスパネルでドローコール数とフレーム時間を確認するのが近道です。
